# 相似选股测试册

两段模板是回归这套打分用的。分数是候选到模板的距离，越小越近；和模板完全相同才会接近 0。页面、下面的函数和 CLI 走同一条 `screen_similar`。观察用。

候选尾部取库里最新一个完整交易日。2026-09-29 当天还没有日 K，下面两次排名的尾部都是 **2026-09-28**（5222 只，和前几个完整交易日同一量级，没有被当成半截交易日丢掉）。指数也到这一天。

## 怎么跑

预发：<http://139.224.244.214/stage/?page=similar>

页上「测试 demo」选远东股份或超声电子。召回池默认 500，打分偏好默认偏筹码。改完要点金色按钮。

```python
from whaletrail.screen import DEMOS, WEIGHT_PRESETS, screen_similar
from whaletrail.similarity import build_scan_pool

spec = DEMOS["chaosheng"]  # 或 "yuandong"
template, pool, n = build_scan_pool(bars, spec["symbol"], spec["start"], spec["end"])
hits, info = screen_similar(
    template, pool, recall_n=500, weights=WEIGHT_PRESETS["偏筹码"],
)
# hits[0].score 越小越近；hits[0].features 是那只的读数
# info["template_stage"] / info["template_features"] 是模板自己的读数
```

`bars` 是 `Repository.daily_bars` 的全市场日 K，并且已经过 `trim_partial_session`。CLI 把这件事包好了。在 `projects/whaletrail` 下：

```bash
.venv/bin/python scripts/similar-screen.py --demo yuandong --recall 500 --top 30
.venv/bin/python scripts/similar-screen.py --demo chaosheng --recall 500 --top 30
.venv/bin/python scripts/similar-screen.py --symbol sz.000823 --start 2026-03-07 --end 2026-09-07 --json /tmp/chaosheng.json
```

`--json` 写出召回池里每一只的分组距离和读数。`--preset` 取偏筹码、均衡、偏确认。旧命令 `scripts/ashare-similar.py` 仍是整段换手 L1 加筹码 EMD。

三档权重是起点，留着看哪一组该加重，不是用这 500 只标定出来的。

| 组 | 偏筹码 | 均衡 | 偏确认 | 读什么 |
|----|--------|------|--------|--------|
| 筹码 | 0.50 | 0.30 | 0.25 | 末日、该股自己的 A 峰日、谷日：峰数、离散（标准差/收盘）、偏度、收盘下方的质量 |
| 做盘痕迹 | 0.15 | 0.20 | 0.15 | 此前最大一段急跌的幅度、速度、最长连阴、从谷底修复了多少 |
| 量 | 0.15 | 0.20 | 0.30 | 末日量 / 此前放量峰、末日量 / 前 20 日均量、末日换手 |
| 箱体 | 0.10 | 0.15 | 0.10 | 谷到期末的宽度/收盘、Choppiness、效率比、收盘在箱内的位置 |
| 确认 | 0.05 | 0.10 | 0.15 | 末日涨跌、收盘在当天高低之间的位置 |
| 均线 | 0.05 | 0.05 | 0.05 | 收盘相对 MA7/30/55/120；四条都在价格上方时记 1 |

缺一项就跳过该项，分母按实际有读数的组重算。A 峰只说明这只股票自己此前有过一段急跌，不跟模板对日期。

## 表上的背景

这几列不进分数，也不剔除任何一只。看的是候选窗口最后一天。

| 列 | 怎么读 |
|----|--------|
| 属性 | 沪主板、深主板、创业板、科创板、北交所，按代码 |
| 行业 | 证监会大类，去掉字母数字前缀后取前六个字 |
| 流通市值 | 收盘 × 成交量 × 100 / 换手，单位亿。库里没有总市值 |
| 体量 | 不到 30 亿偏小，30–100 亿合适，100–300 亿偏大，300–1000 亿大，1000 亿及以上超大。合适档是几十亿 |
| 对上证 | 个股当天涨跌相对上证指数 |
| 对板块 | 相对该股证监会行业当天的等权涨跌。停牌和 ST 不算，行业里至少 8 只有行情才写 |

顺涨、顺跌是两边同向。逆涨、逆跌是方向相反。两边涨跌都不到 0.1 个百分点记为平。只有个股在动、指数或板块几乎没动，记为独立。个股没动、对面在动，记为未跟。创业板另外对照创业板指，深主板另外对照深证成指，写在点评里，不单开一列。科创50不在库里，科创板的大盘对照就是上证。没有概念板块。

## 点评话术

点开一只，或者 CLI 打出的每一段，都按这个顺序。顺序不换。

1. 波形。召回前 80 名写前排，81–200 写中部，再往后写后部，并说明名次是后面的特征抬上来的。归一化收盘相关低于 −0.3 时带上这个数。
2. 近期走势。此前回撤、最长连续收跌、从谷底修回了这段跌幅的多少、收盘在谷后箱内的位置。修回比例比蓝本高出 0.15 以上，写已经离开谷底。
3. 阳线和放量。末日涨跌、收在当日区间的位置、前峰量比、20 日量比、换手。前峰量比达到蓝本的 75%，或者 20 日量比达到蓝本的 85% 并且仍然大于 1，写量能靠近。收阳还要收在当日区间 0.60 以上，才算末端确认齐了。
4. 均线。价格相对 MA7、MA30、MA55、MA120。四条都在价格上方单独写出来。蓝本若是短均在价格下、长均还在价格上，候选也要同侧。
5. 筹码。末日峰数、主峰在收盘上还是下、获利、离散，加上峰日和谷日的获利。峰数要和蓝本一样，末日获利相差不超过 20 个百分点，主峰相对收盘相差不超过 8 个百分点，谷日获利与蓝本相差不超过 10 个百分点，才算同一阶段。
6. 当天背景。属性，以及相对上证、相对自己行业的方向。这句不参加下一句的判断。
7. 判断。波形至少在中部，筹码同一阶段，末日收阳并且量能靠近、收在当日区间 0.60 以上，均线同侧，修复还没有明显离开蓝本：这几条齐了，才写近期有沿这段结构走出来的可能。波形在后部而其余齐了，写形状这一关还不齐。均线同侧但只齐了筹码或末端其中一段，写读数不齐。筹码已经同侧、末端或均线没叠上，写筹码靠近、近期按这段去看拉升不成立。只有末端齐了，写末端有阳线放量、其余还没到那一侧。四条均线都在价格上方，或者这几侧都对不上，也写不成立。体量接在这句后面。合适档照写几十亿。偏大写过了一百亿、幅度会更钝。大档和超大档把「走出来的可能」改成往下看。
